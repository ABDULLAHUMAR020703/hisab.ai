# Import/Export Test Data

Realistic fixtures for validating the Hisab.ai Import/Export Framework across all migrated flat CRUD modules.

## Regenerate

```bash
npm run generate:test-data
```

## Structure

```
test-data/
├── customers/          small.csv|xlsx, medium.csv|xlsx, large.csv|xlsx
├── vendors/
├── inventory/
├── accounts/
├── cost-centers/
├── employees/
├── tax-rates/
├── edge-cases/         Invalid/malformed files for negative testing
│   ├── customers/
│   ├── employees/
│   ├── inventory/
│   ├── accounts/
│   └── tax-rates/
└── performance-results.json   Auto-generated by npm run test:import-export
```

## Dataset sizes

| Size   | Rows |
|--------|------|
| small  | 10   |
| medium | 100  |
| large  | 1000 |

Each module folder contains both **CSV** and **Excel (.xlsx)** for every size.

## Data characteristics

- **Customers / Vendors**: Saudi, Pakistan, and UAE companies with realistic names, VAT/TRN (Saudi), phones, and addresses. Includes Arabic company names.
- **Inventory**: Hardware, software, services, supplies with SKU codes and pricing.
- **Chart of Accounts**: Standard GL structure (assets, liabilities, equity, income, COGS, expenses).
- **Cost Centers**: LOCATION, CLASS, and PROJECT types interleaved.
- **Employees**: Realistic names, departments, salaries, joining dates.
- **Tax Rates**: Standard VAT 15%, zero-rated, exempt, withholding, etc.

## Automated tests

```bash
npm run test:import-export
```

Runs 104 unit/integration tests covering parsing, auto-mapping, validation, edge cases, export, and performance benchmarks.
